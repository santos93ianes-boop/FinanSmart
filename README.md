# FinanSmart V1

Aplicativo Android de organização financeira pessoal, familiar, patrimonial e empresarial.

## APK pelo GitHub
1. Crie um repositório novo no GitHub.
2. Envie **todo o conteúdo desta pasta** para a raiz do repositório.
3. Abra **Actions** > **Build FinanSmart APK** > **Run workflow**.
4. Quando finalizar, abra a execução e baixe o artefato **FinanSmart-v1-debug-apk**.
5. Extraia o ZIP do artefato e instale `app-debug.apk` no Android.

O workflow também roda automaticamente a cada push na branch main/master.
